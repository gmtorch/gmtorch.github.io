gmtorch.arithmetic.substract_independent_gmms(gm0: GaussianMixture, gm1: GaussianMixture) → GaussianMixture[source]#

Return the distribution of the difference of two independent Gaussian mixtures.

Every pair of input components produces one output component. For component indices (i, j), the output weight is w0[i] * w1[j], the output mean is mu0[i] - mu1[j], and the output covariance is cov0[i] + cov1[j].

Parameters:

  • gm0 (GaussianMixture) – Gaussian mixture from which gm1 is subtracted.

  • gm1 (GaussianMixture) – Independent Gaussian mixture to subtract. It must have the same dimension and device as gm0.

Returns:

Exact Gaussian-mixture distribution of the independent difference. The input mixtures are not modified.

Return type:

GaussianMixture

Raises:

ValueError – If the input dimensions or devices differ.

Notes

Independence is a semantic requirement and cannot be inferred from the two marginal distributions alone. The result has gm0.n_components * gm1.n_components components.

gmtorch.fusion.bayesian_fusion_gmm(gm0: GaussianMixture, gm1: GaussianMixture, block_size: int = 128) → GaussianMixture[source]#

Fuse two Gaussian mixtures by taking the normalized product of their densities.

This function computes the Bayesian fusion of two Gaussian mixtures gm0 and gm1 with matching dimensionality. Each pair of components (i, j) produces one fused Gaussian with: - covariance (Sigma0_i^{-1} + Sigma1_j^{-1})^{-1}, - mean weighted by the summed precision-mean products, - unnormalized weight equal to the product of component weights scaled by

the Gaussian overlap term.

The resulting mixture has gm0.n_components * gm1.n_components

Parameters:

  • gm0 (GaussianMixture) – First input Gaussian mixture.

  • gm1 (GaussianMixture) – Second input Gaussian mixture. Must have the same dim as gm0.

  • block_size (int, default=128) – Block size used for blocked pairwise computation to control memory use. Must be a strictly positive integer.

Returns:

The fused Gaussian mixture distribution representing the normalized product p(x) ∝ p_gm0(x) * p_gm1(x).

Return type:

GaussianMixture

gmtorch.propagation.closed_form_propagation(gm: GaussianMixture, operations: Iterable[ClosedFormStep], *, max_components: int | None = None) → GaussianMixture[source]#

Exactly propagate a Gaussian mixture through a chain of closed-form operations.

Each operation may either implement ClosedFormOperation.apply or be a callable with signature GaussianMixture -> GaussianMixture. The input mixture is cloned before the first operation, so built-in operation chains do not mutate the caller’s mixture.

Parameters:

  • gm (GaussianMixture) – Input Gaussian mixture.

  • operations (Iterable[ClosedFormStep]) – Exact propagation operations applied sequentially.

  • max_components (int, optional) – Maximum allowed component count after any operation. This is useful because sums, differences, and fusions multiply component counts.

Returns:

Exact Gaussian mixture after all operations have been applied.

Return type:

GaussianMixture

Raises:

  • TypeError – If an operation is neither callable nor implements apply, or if an operation does not return a GaussianMixture.

  • ValueError – If max_components is invalid or the propagated mixture exceeds it.

Approximate the pushforward of a Gaussian mixture through func.

This function draws samples from gm, applies func to the sample batch, and fits a new full-covariance Gaussian mixture to the transformed samples using GaussianMixtureEstimator.

Parameters:

  • gm (GaussianMixture) – Input Gaussian mixture.

  • func (Callable[[Tensor], Tensor]) – Batch function applied to samples from gm. It receives a tensor of shape (n_samples, gm.dim) and must return either a tensor of shape (n_samples, output_dim) or a vector of shape (n_samples,).

  • n_samples (int) – Number of samples to draw from the input mixture.

  • target_k (int) – Number of components in the fitted output mixture.

  • fit_kwargs (Mapping[str, object], optional) – Additional keyword arguments forwarded to GaussianMixtureEstimator. Use sample_seed for the input-mixture sampling seed and fit_kwargs={"seed": ...} for the EM initialization seed.

  • sample_seed (int, optional) – Seed used only when sampling from gm.

Returns:

Gaussian-mixture approximation to func(X).

Return type:

GaussianMixture

Raises:

ValueError – If sample counts, target component count, fit arguments, or transformed samples are invalid.

PyTorch EM estimator for full-covariance Gaussian mixtures.

This class should own fitting state and training metadata. The existing GaussianMixture class should remain the distribution/value object, while this estimator learns parameters and exposes to_mixture to build that distribution.

Conceptual responsibilities:

  • parameter initialization through _initialize_parameters and _initial_responsibilities;

  • E-step orchestration inherited from BaseMixtureEM;

  • M-step parameter updates through _m_step;

  • log-probability computation through _estimate_log_component_prob;

  • covariance estimation through module-level covariance helpers;

  • prediction and responsibility computation inherited from BaseMixtureEM;

gmtorch.propagate_gmm(gm: GaussianMixture, func: Callable[[Tensor], Tensor], n_samples: int, target_k: int, fit_kwargs: Mapping[str, object] | None = None, *, sample_seed: int | None = None) → GaussianMixture[source]#

Approximate the pushforward of a Gaussian mixture through func.

This function draws samples from gm, applies func to the sample batch, and fits a new full-covariance Gaussian mixture to the transformed samples using GaussianMixtureEstimator.

Parameters:

  • gm (GaussianMixture) – Input Gaussian mixture.

  • func (Callable[[Tensor], Tensor]) – Batch function applied to samples from gm. It receives a tensor of shape (n_samples, gm.dim) and must return either a tensor of shape (n_samples, output_dim) or a vector of shape (n_samples,).

  • n_samples (int) – Number of samples to draw from the input mixture.

  • target_k (int) – Number of components in the fitted output mixture.

  • fit_kwargs (Mapping[str, object], optional) – Additional keyword arguments forwarded to GaussianMixtureEstimator. Use sample_seed for the input-mixture sampling seed and fit_kwargs={"seed": ...} for the EM initialization seed.

  • sample_seed (int, optional) – Seed used only when sampling from gm.

Returns:

Gaussian-mixture approximation to func(X).

Return type:

GaussianMixture

Raises:

ValueError – If sample counts, target component count, fit arguments, or transformed samples are invalid.
